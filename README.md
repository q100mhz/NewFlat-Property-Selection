# Подборка объектов newflat72.ru для Битрикс24

Локальное приложение Битрикс24 для агентства недвижимости. В карточках **лида** и **сделки** появляется вкладка **«Подборка»**:

1. Сотрудник собирает подборку из каталога newflat72.ru (фильтры: категория, комнаты, цена, площадь, адрес/ЖК/район) или вставляет ссылку на объект с сайта.
2. Приложение создаёт короткую ссылку для клиента и пишет её в таймлайн карточки.
3. Клиент открывает ссылку с телефона и по каждому объекту отмечает «Нравится» / «Не подходит» с причиной (цена, район, планировка, этаж и т. д.) и комментарием, а также может отметить «Хочу посмотреть вживую». Кнопки «Отправить» нет: каждая отметка и комментарий сохраняются сразу.
4. Вкладка у риелтора обновляется в реальном времени (Server-Sent Events): оценки и комментарии клиента появляются через секунду, со статусом «Клиент оценивает сейчас». Когда клиент 5 минут ничего не меняет (`DIGEST_DELAY_MIN`), в таймлайн карточки добавляется сводка, а автор подборки и ответственный получают уведомление; при новых изменениях придёт обновлённая сводка. При первом открытии ссылки тоже приходит уведомление.
5. Все подборки хранятся во вкладке вместе с оценками. Кнопка «Новая подборка на основе» переносит понравившиеся и неоценённые объекты в следующую подборку. Объекты, которые клиент уже видел, помечаются в каталоге «Уже отправляли 👍/👎».
6. Страница приложения (меню «Приложения») — дашборд: быстрые периоды (сегодня, вчера, неделя, месяц, произвольный), фильтры по сотруднику и статусу, показатели, разбивка по сотрудникам, реестр. Права: администраторы портала, руководитель головного подразделения и пользователи с «полным доступом» видят всё; руководитель подразделения — себя и сотрудников своего и вложенных подразделений; сотрудник — только свои подборки.
7. Если лид конвертировали в сделку, во вкладке сделки видны и подборки исходного лида.

## Как это устроено

| Компонент | Что делает |
|---|---|
| `src/catalog/` | Раз в 6 часов обходит разделы каталога newflat72.ru (≈400 страниц) и сохраняет карточки в SQLite. Карточку объекта (все фото, характеристики, описание) загружает при добавлении в подборку и кэширует на 12 часов. Снятые с сайта объекты помечаются в подборках. |
| `src/bitrix.js` | OAuth и REST Битрикс24: установка, регистрация вкладок `CRM_LEAD_DETAIL_TAB` / `CRM_DEAL_DETAIL_TAB`, автообновление токенов. |
| `src/selections.js` | Подборки, снимки объектов на момент отправки, реакции клиента, комментарий в таймлайн, уведомления. |
| `src/images.js` | Прокси с дисковым кэшем для фото сайта (сайт иногда обрывает соединения). |
| `public/app/` | Интерфейс вкладки в карточке CRM и страница приложения из меню (статус каталога, журнал подборок). |
| `public/client/` | Страница подборки для клиента (`/s/<токен>`), рассчитана в первую очередь на телефон. |

Данные хранятся в `data/app.sqlite` (в Docker — в томе `propertyselection_data`), кэш фото — в `data/img-cache/`. Резервная копия базы: `npm run backup`.

## Развёртывание

Приложение запускается в Docker (`Dockerfile`, `docker-compose.yml`) и слушает `127.0.0.1:3200`; наружу его публикует nginx с сертификатом Let's Encrypt. Пошаговая инструкция для сервера 89.111.170.193 — в [DEPLOY.md](DEPLOY.md).

Без Docker приложение тоже можно запустить: Node.js 20+, `npm ci --omit=dev`, служба из `deploy/propertyselection.service`.

## Подключение к Битрикс24

1. Портал агентства → **Разработчикам → Другое → Локальное приложение**.
2. Тип: **Серверное**, «Использует только API» — **нет** (у приложения есть интерфейс).
3. Путь вашего обработчика: `https://propertyselection.itb2bhost.ru/b24/handler`
4. Путь для первоначальной установки: `https://propertyselection.itb2bhost.ru/b24/install`
5. Права: **CRM (crm)**, **Встраивание приложений (placement)**, **Чат и уведомления (im)**, **Пользователи (user)**, **Структура компании (department)**.
6. Сохраните. Скопируйте «Код приложения» и «Ключ приложения» в `.env` (`B24_CLIENT_ID`, `B24_CLIENT_SECRET`), укажите домен портала в `B24_ALLOWED_DOMAINS` и перезапустите сервис: `sudo systemctl restart propertyselection`.
7. Откройте приложение в разделе «Приложения» — установка зарегистрирует вкладку «Подборка» в лидах и сделках.

Если вкладка не появилась, переустановите приложение: обработчик установки заново привяжет встройки.

## Локальная разработка

```bash
npm install
npm run dev        # DEV_MODE: http://localhost:3000/dev/placement?entity=lead&id=1
npm test
```

В режиме разработки вкладку можно открыть без Битрикс24. Комментарии в таймлайн и уведомления при этом не отправляются. Для быстрого старта ограничьте обход каталога: `CRAWL_MAX_PAGES=2`.

## Настройки (`.env`)

| Переменная | Назначение |
|---|---|
| `BASE_URL` | Публичный адрес приложения, из него строятся ссылки для клиентов |
| `B24_CLIENT_ID`, `B24_CLIENT_SECRET` | Ключи локального приложения |
| `B24_ALLOWED_DOMAINS` | Домены порталов, которым разрешено работать с приложением |
| `SESSION_SECRET` | Секрет для подписи сессий сотрудников (`openssl rand -hex 32`) |
| `CRAWL_INTERVAL_HOURS` | Как часто обновлять каталог (по умолчанию 6) |
| `AGENCY_NAME`, `AGENCY_PHONE`, `AGENCY_LOGO` | Оформление страницы для клиента |
| `APP_TIMEZONE` | Часовой пояс агентства для названий подборок и периодов дашборда (по умолчанию `Asia/Yekaterinburg` — Тюмень) |
| `DIGEST_DELAY_MIN` | Через сколько минут тишины после последней оценки клиента писать сводку в таймлайн (по умолчанию 5) |

Разделы каталога и причины отказа задаются в `src/config.js` (`CATALOG_SECTIONS`, `DISLIKE_REASONS`).
